## Windows icon fonts
`scripts/install-fonts.ps1` installs local copies of icon fonts that already ship with Windows
(*Settings Fluent Icons*, *Settings MDL2 Assets*, *SysBatt Fluent Icons*) from the user's own
`C:\Windows` folders, so the Gridline font rules can fall back to them. These files are not part of
this repository and are not redistributed.
