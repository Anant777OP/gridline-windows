# Changelog

## 1.0.0
First public release.

- Styler themes for the taskbar (floating dock), Start menu and its search page, Quick Settings and
  notifications, File Explorer and Settings: near-black surfaces, cyan lines, orange second
  accent, Orbitron and Share Tech Mono, in dark and light.
- *Gridline Desktop* Windhawk mod: 12 light-line desktop widgets with corner-bracket cards, a Pulse
  notification light and a "Keep Gridline cursors and sounds" option.
- *Gridline Window Frames* Windhawk mod: near-black title bars and thin cyan borders.
- Gridline Icons line icon font for Quick Settings and the tray.
- Gridline Pointer cursors (Carbon and Clear), synth UI sounds, Gridline Clock screensaver with a
  moving floor grid.
- Gridline icons for folders, special folders, This PC, Home, Gallery, Network, Recycle Bin and drives.
- 16 neon-grid wallpapers.
- One-step `install.ps1` / `uninstall.ps1`, light/dark and on/off switches, automatic Windhawk
  detection (portable or installed), backups for every change.
